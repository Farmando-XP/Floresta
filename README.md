# Floresta — Landing Page

Landing page institucional desenvolvida no **Farmando XP**, projeto de extensão do IFTM Campus Patrocínio, com orientação do prof. Gilberto Viana de Oliveira (2026).

**Cliente:** [Floresta Supermercado e Padaria, [Patrocínio-MG]
**Equipe:** Gabriel Augusto, Gabriel Mendes, João Marcelo

Seções:
- Cabeçalho (header) com menu de navegação
- Nossa História
- Nossas Quitandas (carrossel)
- Outros setores (carrossel)
- Localização (mapa, endereço e contatos)
- Rodapé
